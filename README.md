## 📖 Descripción del Proyecto

Este repositorio contiene un **Análisis Exploratorio de Datos (EDA)** y un **informe de inteligencia de negocios** aplicado a la cadena minorista **Alura Store LATAM**.

A partir de datos transaccionales reales (ventas, costos de envío, calificaciones y categorías de productos), se evalúa el desempeño integral de **cuatro sucursales**, con el fin de respaldar una **decisión estratégica de negocio basada en datos**.

El proyecto combina análisis cuantitativo, visualización de datos y razonamiento estratégico.

---

## 🎯 Objetivo de Negocio

El CEO de la empresa, **Sr. Juan**, necesita liberar capital para financiar un nuevo emprendimiento.  
La pregunta central que guía este análisis es:

> **¿Qué tienda debe ser vendida para obtener liquidez, minimizando el impacto negativo en los ingresos y en la reputación de la empresa?**

Para responderla, se analizan cuatro pilares clave:
- Rentabilidad financiera
- Satisfacción del cliente
- Eficiencia logística
- Desempeño comercial por producto y categoría
